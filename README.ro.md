## 👋 Despre

Dezvolt add-onuri pentru Kodi care îți simplifică experiența: surse HTTP și debrid de top, subtitrări instant și unelte de întreținere fără bătăi de cap.

Toate add-onurile se găsesc în repository-ul oficial:

👉 **[repository.angelitto](https://angelitto2005.github.io/repository.angelitto/)**

> **Compatibilitate:** Testat pe **Kodi 20 Nexus, 21 Omega și 22 Piers**.

---

## ⚡ Instalare Rapidă

**1.** În Kodi, mergi la `Setări → File Manager → Add Source` și adaugă:

```
https://angelitto2005.github.io/repository.angelitto/
```

**2.** Mergi la `Setări → Add-onuri → Install from zip file` și selectează sursa adăugată pentru a instala **repository.angelitto**.

**3.** Mergi la `Setări → Add-onuri → Install from repository → Angelitto Repository` și instalează orice add-on de mai jos.

## 🔥 Proiectele Mele

| Add-on | Ce face |
| ------ | ------- |
| **TMDb Movies** | Filme și seriale prin **streamuri HTTP, P2P și servicii debrid**. Bazat pe **AIO Streams, Torrentio, MediaFusion, Comet, Meteor, StremThru** și multe altele. **Suport TorrServer.** Liste Trakt / Simkl / MDBList / TMDb incluse. ## ⭐ Spotlight: TMDb Movies

Add-onul meu principal pentru filme și seriale.

### Ce primești

- **Streaming pentru toți:** peste 20 de site-uri HTTP fără debrid (MovieBox, Flixer, Cineby, VidLink și altele), AIO Streams + Stremio cu debrid (Torrentio, MediaFusion, Comet, Meteor, StremThru Torz, Usenet, add-onuri custom) și P2P prin **TorrServer** — trackere publice (YTS, TPB, Knaben) și private (FileList, SpeedApp, SeedPool)
- **Redare inteligentă:** sortare surse și Smart Cache retry, auto-play cea mai bună sursă, excluderi pe calitate (4K / HDR / DV)
- **Seriale fără pauză:** auto-play episodul următor, dialog Skip Intro, Up Next + Calendar cu sincronizare watched și rating post-vizionare pe Trakt / MDBList / Simkl / TMDb, plus backup local al istoricului
- **Liste și import:** import/export Trakt, Simkl, MDBList și TMDb (istoric + watchlisturi) + **Up Next + Calendar** TMDb
- **Descoperire:** navigare pe Actori, secțiuni dedicate **Romania** și Bollywood / Detonate, căutare YouTube cu autoplay pentru videoclipuri sugerate, integrare MDBLists
- **Trailere:** integrare dedicată TMDbM Trailers cu fix GeoLocation (sau pluginul YouTube)
- **My Plays — redare oriunde:** trimite orice titlu direct către add-onuri externe precum **POV, Umbrella, Fen, Fen Light, Seren, RedLight, Elementum, TMDB Helper** și altele, chiar din TMDb Movies
- **Nativ Kodi:** export în Library cu auto-sync, meniuri contextuale Add to Library + TMDb Info, TMDb Extended Info + descrieri localizate (en / ro / es, fr...), meniuri personalizabile, și multe altele
