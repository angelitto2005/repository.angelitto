## 👋 About

I'm a passionate developer building Kodi add-ons that make streaming simpler and better: top-tier HTTP and debrid sources, instant subtitles, and hassle-free maintenance tools.

All add-ons are distributed through my official repository:

👉 **[repository.angelitto](https://angelitto2005.github.io/repository.angelitto/)**

> **Compatibility:** Tested on **Kodi 20 Nexus, 21 Omega and 22 Piers**.

---

## ⚡ Quick Install

**1.** In Kodi, go to `Settings → File Manager → Add Source` and add:

```
https://angelitto2005.github.io/repository.angelitto/
```

**2.** Go to `Settings → Add-ons → Install from zip file` and select the source you just added to install **repository.angelitto**.

**3.** Go to `Settings → Add-ons → Install from repository → Angelitto Repository` and install any add-on below.

## ⭐ Spotlight: TMDb Movies

My flagship video add-on for movies and TV shows.

### What you get

- **Streaming for everyone:** 20+ no-debrid HTTP sites (MovieBox, Flixer, Cineby, VidLink and more), AIO Streams + Stremio debrid (Torrentio, MediaFusion, Comet, Meteor, StremThru Torz, Usenet, custom add-ons), and P2P via **TorrServer** — public (YTS, TPB, Knaben) and private (FileList, SpeedApp, SeedPool) trackers
- **Smart playback:** source sorting and Smart Cache retry, auto-play best source, quality exclusions (4K / HDR / DV)
- **Binge-ready TV:** auto-play next episode, Skip Intro dialog, Up Next + Calendar with watched sync and post-watch rating on Trakt / MDBList / Simkl / TMDb, plus local history backup
- **Lists & import:** Trakt, Simkl, MDBList and TMDb import/export (history + watchlists) + TMDb **Up Next + Calendar**
- **Discovery:** Actors browser, dedicated **Romania** and Bollywood / Detonate sections, YouTube search with autoplay of suggested videos, MDBLists integration
- **Trailers:** dedicated TMDbM Trailers integration with GeoLocation fix (or YouTube plugin)
- **My Plays — play anywhere:** send any title directly to external add-ons like **POV, Umbrella, Fen, Fen Light, Seren, RedLight, Elementum, TMDB Helper** and more, right from TMDb Movies
- **Kodi-native:** Library export with auto-sync, Add to Library + TMDb Info, TMDb Extended Info context menus + localized plots (en / ro / es, fr...), customizable menus, and much more
